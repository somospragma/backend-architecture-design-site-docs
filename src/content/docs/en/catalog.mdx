Each artifact in the catalog shows:

- what it solves, in one sentence;
- kind: library, plugin, CLI, template, tool, SDK or action;
- ecosystems, such as Java, Node or AWS;
- origin: official or community;
- status: `experimental`, `beta`, `stable` or `deprecated`;
- who maintains it and where the code lives.
