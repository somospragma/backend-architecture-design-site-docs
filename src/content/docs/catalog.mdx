<Aside type="note" title="Aún no hay artefactos">
	El catálogo está listo, pero todavía no tiene fichas. Si construiste algo que le sirve a otros, [agrégalo](../contribute/).
</Aside>

Cada artefacto del catálogo muestra:

- qué resuelve, en una frase;
- tipo: librería, plugin, CLI, plantilla, herramienta, SDK o action;
- ecosistemas, como Java, Node o AWS;
- origen: oficial o comunidad;
- estado: `experimental`, `beta`, `stable` o `deprecated`;
- quién lo mantiene y dónde está el código.
